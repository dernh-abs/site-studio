# Puck canvas for DOM-injected clones

The earlier version of this skill said a DOM-injected clone has no component
tree, "so a Puck canvas has nothing to render — use a translation-editor
table." **That is outdated.** The proven build now gives a DOM-injected clone
the **full Puck canvas** (left outline, center canvas, right property panel)
by splitting the injected HTML into blocks and registering one generic
`PageBlock` component per block. This file is the complete template.

## Data flow (canvas)

```
public/studio-blocks/{slug}.json   (generated by scripts/gen-blocks.py)
        │  blocks: [{id,title,html,keys,images}]
        ▼
buildPageConfig(blocks)  ──►  Puck config: one component per block
        │                        render = <PageBlock html keys images …props/>
        ▼
ucdToPuck(doc, page, blocks) ──► PuckData { content:[{type:id, props}] }
        │                        props[sanitizeKey(k)] = merged text value
        │                        props[imgKey] = current image URL
        ▼
<Puck data=…> renders each PageBlock via dangerouslySetInnerHTML,
        substituting edited values with html.split(original).join(edited)

edit in right panel ──► onChange ──► puckToUcd ──► savePatch ──► POST /api/studio/patch
```

## 1. Block model + conversion — `src/lib/puck/puck-adapter.ts`

```ts
import type { UnifiedContentDocument } from "@/lib/content/content-schema";
import { compatTranslate } from "@/lib/content/compat-adapter";
import { TRANSLATIONS } from "@/lib/i18n/translations";

export interface PuckData {
  content: Array<{ type: string; props: Record<string, unknown> }>;
  root: { props?: Record<string, unknown> };
}

export interface PageBlockInfo {
  id: string;
  title: string;
  html: string;
  keys: string[];                          // real flat text keys (dotted)
  images?: { key: string; url: string }[]; // key = "<slug>__<blockId>__img<n>"
}

// Text keys contain dots ("index.span.2") which Puck treats as nested object
// paths. Sanitize dots -> "__" so a key becomes a flat prop name.
export function sanitizeKey(key: string): string {
  return key.replace(/\./g, "__");
}

export function ucdToPuck(doc, page, blocks): PuckData {
  if (!doc) return { content: [], root: {} };
  const en = (doc.translations?.en ?? {}) as Record<string, unknown>;
  return {
    content: blocks.map((b) => {
      const props: Record<string, unknown> = {
        id: b.id, html: b.html, keys: b.keys, images: b.images ?? [],
      };
      for (const key of b.keys)
        props[sanitizeKey(key)] = compatTranslate("en", doc.translations ?? null, key);
      for (const img of b.images ?? [])
        props[img.key] = typeof en[img.key] === "string" ? en[img.key] : img.url;
      return { type: b.id, props };
    }),
    root: {},
  };
}

export function puckToUcd(puckData, currentUcd, _page, blocks) {
  const newUcd = JSON.parse(JSON.stringify(currentUcd));
  const en = (newUcd.translations.en ?? {}) as Record<string, unknown>;
  const blockMap = new Map(blocks.map((b) => [b.id, b]));
  for (const item of puckData.content) {
    const props = (item.props ?? {}) as Record<string, unknown>;
    const keys = Array.isArray(props.keys) ? (props.keys as string[]) : [];
    for (const key of keys) {
      const v = props[sanitizeKey(key)];
      if (typeof v === "string") en[key] = v;
    }
    const blk = blockMap.get(String(item.type));
    for (const img of blk?.images ?? []) {
      const v = props[img.key];
      if (typeof v === "string") en[img.key] = v;
    }
  }
  return newUcd;
}

export function baselineValue(key: string): string {
  const en = (TRANSLATIONS.en?.translation ?? {}) as Record<string, string>;
  return en[key] ?? "";
}
export function baselineImage(blocks: PageBlockInfo[], key: string): string {
  for (const b of blocks)
    for (const img of b.images ?? [])
      if (img.key === key) return img.url;
  return "";
}
// Human-readable title for the outline: first non-empty text value, truncated.
export function resolveBlockTitle(props: Record<string, unknown>): string {
  const keys = Array.isArray(props.keys) ? (props.keys as string[]) : [];
  for (const k of keys) {
    const v = props[sanitizeKey(k)];
    if (typeof v === "string" && v.trim()) {
      const t = v.trim().replace(/\s+/g, " ");
      return t.length > 36 ? t.slice(0, 36) + "…" : t;
    }
  }
  return (typeof props.id === "string" && props.id) || "Untitled";
}
```

## 2. Generic PageBlock + config — `src/lib/puck/puck-config.tsx`

```tsx
import type { Config } from "@measured/puck";
import { TRANSLATIONS } from "@/lib/i18n/translations";
import { PageBlockInfo, sanitizeKey } from "./puck-adapter";

export function PageBlock(props: {
  id?: string; html?: string; keys?: string[]; images?: { key: string; url: string }[];
  [key: string]: unknown;
}) {
  const html = typeof props.html === "string" ? props.html : "";
  const keys = Array.isArray(props.keys) ? (props.keys as string[]) : [];
  const images = Array.isArray(props.images) ? (props.images as { key: string; url: string }[]) : [];
  const base = (TRANSLATIONS.en?.translation ?? {}) as Record<string, string>;

  let out = html;
  for (const key of keys) {
    const value = props[sanitizeKey(key)];
    if (typeof value !== "string") continue;
    const original = base[key];
    if (!original || value === original) continue;
    out = out.split(original).join(value);
  }
  for (const img of images) {
    const value = props[img.key];
    if (typeof value !== "string" || value === img.url) continue;
    out = out.split(img.url).join(value);
  }
  return <div dangerouslySetInnerHTML={{ __html: out }} />;
}

export function buildPageConfig(blocks: PageBlockInfo[]): Config<any> {
  const components: Record<string, unknown> = {};
  for (const block of blocks) {
    const fields: Record<string, unknown> = {};
    for (const key of block.keys)
      fields[sanitizeKey(key)] = { type: "textarea", label: key };
    for (const img of block.images ?? [])
      fields[img.key] = { type: "image", label: img.key };
    components[block.id] = {
      label: block.title,
      fields,
      render: (props: any) => <PageBlock {...props} />,
    };
  }
  return { components } as Config<any>;
}
```

**Key idea:** the "component tree" is recovered from the injected HTML, not the
original React source. `PageBlock` is the one generic component; its fields are
the block's text keys (textarea) and image keys (image). Selecting a block in
the outline shows its keys in the right panel — a shorter, scoped editor per
block (this is why splitting the page into blocks matters: one 46-key `<main>`
becomes a 4-key hero + a 42-key list).

## 3. The three Puck pitfalls (all hit in the proven build)

### 3a. `data` prop is initialization-only — need a Bridge

Puck's `data` prop seeds its internal Zustand store but is **not** reactively
controlled: setting React state (`setPuckData(next)`) does not re-render the
canvas. To push new data in, you must dispatch `setData` into Puck's store
through `usePuck()`, which is only callable inside a `<Puck>` child. Mount a
bridge via `overrides.header`:

```tsx
const PuckSyncContext = createContext<{ current: ((d: PuckData) => void) | null } | null>(null);

function PuckDataBridge() {
  const { dispatch } = usePuck();
  const sync = useContext(PuckSyncContext);
  useEffect(() => {
    if (!sync) return;
    sync.current = (data) => dispatch({ type: "setData", data });
    return () => { sync.current = null; };
  }, [dispatch, sync]);
  return null;
}

// In PuckEditor:
const puckSyncRef = useRef<((d: PuckData) => void) | null>(null);
const pushPuckData = useCallback((data: PuckData) => {
  setPuckData(data);                 // keep React state in sync
  puckSyncRef.current?.(data);       // push into Puck's internal store
}, []);
```

Every place that "reloads" the canvas (initial load, `refreshDocument`,
optimistic NL apply) must call `pushPuckData(...)`, never `setPuckData` alone.

### 3b. Dot keys are nested paths — sanitize

`hospitals.a.4` would be interpreted by Puck as `{hospitals:{a:{4:…}}}`, so the
prop must be written as `hospitals__a__4`. `sanitizeKey` does this; the block
also carries the real `keys` array so `puckToUcd` can round-trip.

### 3c. Default viewport is 360px — force desktop

Puck defaults to a 360px smartphone iframe, which squashes a desktop clone's
layout and hides the lower sections of a tall page. Force a single desktop
viewport so the whole page (header → main → footer) renders at the right width:

```tsx
<Puck
  viewports={[{ width: 1280, height: "auto", icon: "monitor", label: "Desktop" }]}
  ...
/>
```

With `height: "auto"` Puck auto-zooms to fit the canvas; a long page stays
scrollable inside the frame.

## 4. Custom outline — `overrides.outline`

Replace Puck's default component list with a page-block outline whose rows are
resolved titles. Clicking a row selects that block via `setUi`:

```tsx
import { useGetPuck } from "@measured/puck";

function StudioOutline() {
  const getPuck = useGetPuck();
  const store = getPuck();
  const appState: any = store?.appState ?? {};
  const content = appState?.data?.content ?? [];
  const selected = appState?.ui?.itemSelector ?? null;
  const { dispatch, getSelectorForId } = store ?? {};
  return (
    <div style={{ width: 192, background: "#f9fafb", borderRight: "1px solid #e5e7eb" }}>
      <div style={{ padding: "8px 12px", borderBottom: "1px solid #e5e7eb" }}>
        <span style={{ fontSize: 12, fontWeight: 600, color: "#6b7280" }}>区块 ({content.length})</span>
      </div>
      <ul style={{ listStyle: "none", margin: 0, padding: "4px 0" }}>
        {content.map((item, idx) => {
          const props = (item.props ?? {}) as Record<string, unknown>;
          const id = typeof props.id === "string" && props.id ? props.id : item.type;
          const title = resolveBlockTitle(props);
          const sel = getSelectorForId?.(id);
          const isSelected = !!sel && !!selected && sel.index === selected.index;
          return (
            <li key={`${id}-${idx}`}>
              <button
                type="button"
                onClick={() => sel && dispatch({ type: "setUi", ui: { itemSelector: sel } })}
                style={{ width: "100%", textAlign: "left", padding: "6px 12px",
                         fontSize: 13, background: isSelected ? "#1B4D3E1a" : "transparent",
                         color: isSelected ? "#1B4D3E" : "#374151", border: "none", cursor: "pointer" }}
              >
                <span>{title}</span>
              </button>
            </li>
          );
        })}
      </ul>
    </div>
  );
}
```

Wire it: `overrides={{ outline: () => <StudioOutline /> }}`.

## 5. Image editing (upload + library)

Block images are editable through a custom `image` field type. The chain:

```
puck-config fields[imgKey] = { type: "image" }
   └─ overrides.fieldTypes = { image: ImageField }
        └─ ImageField renders <ImageUploader value onChange/>
             └─ POST /api/studio/upload  (multipart "file") → saveAsset()
                  └─ returns { url, asset } ; url = /uploads/studio/YYYYMM/<hash>.<ext>
```

### 5a. Custom field — `src/lib/puck/custom-field-types.tsx`

```tsx
"use client";
import { ImageUploader } from "@/app/studio/components/ImageUploader";

export function ImageField({ field, value, onChange, readOnly }: any) {
  if (readOnly) {
    return value
      ? <img src={value} alt={field.label ?? "image"} style={{ width: "100%" }} />
      : <span style={{ fontSize: 12, color: "#9ca3af" }}>未设置图片</span>;
  }
  return <ImageUploader value={value ?? ""} onChange={onChange} label={field.label} />;
}
```

### 5b. Upload route — `src/app/api/studio/upload/route.ts`

Multipart `file` → `saveAsset(buffer, name, type)`. Developer-gated. Returns
`{ success, url, asset }`. Limits: **5MB**, MIME ∈ {jpeg, png, webp, svg+xml}.
On an empty body (`request.formData()` throws), return **400** (not 500) — the
proven build hit this when a client sent no file.

### 5c. Asset store — `src/lib/studio/asset-store.ts`

`saveAsset` writes to `public/uploads/studio/YYYYMM/<sha256-16>.<ext>` and
appends `{url, originalName, size, mimeType, uploadedAt, relativePath}` to
`public/uploads/studio/index.json` (atomic tmp+rename, dedup by URL).
`listAssets()` returns newest-first for the library modal.

### 5d. Runtime uploads need a static-file route + rewrite

`next start` only serves `public/` files snapshotted at **build time**, so a
runtime-uploaded image 404s. Add a route that reads from disk — **no developer
gate** (public pages render these images, so they are static-asset semantics):

```ts
// src/app/api/studio/uploads/[path]/route.ts
export async function GET(_req, { params }: { params: Promise<{ path: string }> }) {
  const { path: segs } = await params;      // Next 16: catch-all param is a Promise
  const rel = segs.replace(/\//g, path.sep);
  const abs = path.join(UPLOAD_ROOT, rel);
  if (!abs.startsWith(UPLOAD_ROOT + path.sep))      // path-traversal guard
    return NextResponse.json({ success: false, error: "Forbidden" }, { status: 403 });
  try {
    const data = await fs.readFile(abs);
    return new NextResponse(new Uint8Array(data), {
      headers: { "Content-Type": MIME[path.extname(abs).toLowerCase()] ?? "application/octet-stream",
                 "Cache-Control": "public, max-age=31536000, immutable" },
    });
  } catch { return NextResponse.json({ success: false, error: "Not found" }, { status: 404 }); }
}
```

and in `next.config.mjs`:

```js
async rewrites() {
  return [ { source: "/uploads/:path*", destination: "/api/studio/uploads/:path*" } ];
}
```

### 5e. Image keys are slug-prefixed

Image keys are `{slug}__{blockId}__img{n}` (NOT `{blockId}__img{n}`) because
different pages reuse block ids (`main-0` appears on every page) and a bare
`main-0__img0` would collide across pages. `gen-blocks.py` already emits the
slug prefix. The public page renderer must apply these image keys too —
`applyOverrides` replaces **both** text keys (dotted) **and** image keys
(`slug__` prefix + `__img` suffix).

## 6. Page registry — `/studio` navigation lists real pages

The `/studio` landing page must list pages that actually have a block layout,
not every translation-key prefix (image keys and stale artifacts pollute a
key-prefix scan). Scan `public/studio-blocks/*.json` filenames:

```ts
// src/lib/studio/page-registry.ts  (SERVER-ONLY: node:fs)
const DIR = path.join(process.cwd(), "public", "studio-blocks");
export async function listRegisteredPages() {
  const entries = await fs.readdir(DIR, { withFileTypes: true });
  const out = [];
  for (const e of entries) {
    if (!e.isFile() || !e.name.endsWith(".json")) continue;
    const slug = e.name.slice(0, -".json".length);
    const blocks = JSON.parse(await fs.readFile(path.join(DIR, e.name), "utf-8")).blocks ?? [];
    out.push({ slug, blockCount: blocks.length });
  }
  return out.sort((a, b) => a.slug.localeCompare(b.slug));
}
```

Expose it via `GET /api/studio/pages` (developer-gated) → `{ success, pages: [{slug, blocks}], count }`,
and the navigation page fetches that instead of deriving slugs from
`translations.en` key prefixes.

> **IMPORTANT:** `page-registry.ts` must be **server-only**. Do NOT import
> `node:fs` from a module the client also imports (e.g. `puck-adapter.ts`) —
> that breaks the client bundle with React error #130 ("element type is
> invalid"). Keep fs access in a dedicated `src/lib/studio/*` module the client
> never touches; the client navigates by slug, and only the `/api/studio/pages`
> route imports the registry.

## 7. NL command → canvas (optimistic preview + dom-ops-mapper)

The NL command bar is documented in `references/nl-command-bar.md`. On a
DOM-injected clone, add two pieces:

1. **`dom-ops-mapper`** — the plan generator emits component-rebuild paths
   (`/pages/index/sections/hero/title`, `/translations/en/nav.about`); map them
   to the clone's flat keys. **1:1 first**: if the key is a real baseline key
   (`base[key] !== undefined`, dots intact), keep it literal so the change lands
   on exactly the key shown in the right panel. Only fall back to semantic
   matching (longest text key in the block, header nav-key by tail word) when
   the key is not in the baseline.
2. **Optimistic preview** — on `handleAgentApply`, apply the returned
   `/translations/*` ops to a UCD copy, `ucdToPuck` it, and `pushPuckData` the
   result so the canvas updates instantly (same as editing text in the right
   panel), then persist via `/api/agent/command` (dryRun:false) and
   `refreshDocument()` as the authoritative sync.

## 8. `document` route must re-read disk

Because Next 16 keeps Route Handlers and page rendering in separate module
instances, the `GET /api/studio/document` handler must call `loadFullDocument()`
(which is mtime-validated) on **every** request rather than trusting an
in-memory `getDocument()`. Otherwise an NL command applied in one instance is
invisible to the editor's `refreshDocument()`.

## 9. Toolbar — keep it minimal

The top bar ships with **撤销修改 (undo) + 保存修改 (save)** plus the NL command
bar. Remove Redo / Discard / History / Save Draft / Review / Publish, and hide
Puck's own header (which duplicates undo/redo/publish) by using
`overrides.header` for the bridge (which renders nothing).

## Verification (canvas)

- `npx tsc --noEmit` clean.
- `/studio/{slug}` renders the canvas: header, main sections, footer all visible
  inside the iframe (desktop viewport), with scrollable content below.
- Selecting a block in the outline shows its text keys in the right panel.
- Editing a key → `POST /api/studio/patch` → the public page reflects it.
- Uploading an image → `/uploads/studio/...` returns the image → the canvas and
  public page both swap it in.
- NL command ("把 hero 标题改成 X") applies → canvas updates immediately and the
  public page reflects it after reload.
